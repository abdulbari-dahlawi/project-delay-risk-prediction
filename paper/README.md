# Manuscript Integration

The public code repository does not include reviewer comments or an unpublished manuscript draft by default.

Before submission, update the manuscript to cite the final GitHub URL and Zenodo DOI, and ensure all numerical values come from the archived `FINAL_` outputs.

Recommended repository-aligned manuscript framing:
- synthetic-data proof of concept;
- internal validation, not external validation;
- XGBoost and MLP described as practically equivalent unless paired uncertainty shows otherwise;
- XAI as model explanation, not causal discovery;
- scenario engine as model-based sensitivity analysis, not intervention effectiveness.
